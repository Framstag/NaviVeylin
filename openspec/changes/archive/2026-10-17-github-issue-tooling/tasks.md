# Tasks

This change is spec-owned by `issue-backlog`: `specs/issue-backlog/spec.md` defines it, so each task names the
**design decision** it lands and its verification names the case that exercises it; the traceability task in this change maps every scenario to its case. Every task
carries its own verification.

Scope guard: this change touches **no Gradle source set** — `tools/issues/**` is outside every
module, and no Gradle build or suite is run or required (`guidelines/Build.md` §2, the scope block).
The gate is `tools/issue-tooling-selftest.sh`, which compiles the Java core with `javac --release 17`
and runs every case. No on-device or pixel verification applies: the change produces no UI and
nothing is read on a screen — say so in the change report rather than implying device proof.
