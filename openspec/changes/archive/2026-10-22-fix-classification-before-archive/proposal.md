# Proposal — fix-classification-before-archive

## Why

**Root cause.** `tools/gen-feature-list.sh`'s classification gate read one directory — `openspec/specs/` — so it
could only see a capability *after* the archiving move had put its spec there. The line the archiving change owes
(`guidelines/FeatureList.md` §4) was therefore due at a moment nothing checked, and the first thing that named the
missing line was the run of the *next* change, or a CI step three changes late. `TODO.md` §157 recorded three such
instances (`generate-feature-list`, `routing-max-speed`, `routing-failure-reporting`); its first fix candidate
landed as a CI step over the shipped set, and its second candidate — "make the archive step itself run
`--check-classification` before moving `changeRoot`" — was left open because the archiving skills are generated by
the OpenSpec CLI and are not versioned here.

**The red test.** `tools/gen-feature-list-selftest.sh` gained the case set that exercises an open change's delta
spec; on the run's base commit `80df3a3` it fails:

```
FAIL gate: a capability an open change introduces must be classified
     expected [1], got [0]
     last run: check --check-classification
       unclassified: 0
FAIL gate: the unclassified open capability is named
FAIL gate: the open change that owes the line is named
gen-feature-list-selftest: 112 passed, 3 failed
```

`evidence/red-HEAD.log` (exit 1, `2026-10-22T01:07:48Z`) and `evidence/red-HEAD.xml` (`tests=3 failures=3`) carry it.

**Owning requirement.** `openspec/specs/spec-feature-index/spec.md`, "An unclassified spec id stops the run" —
this delta MODIFIES it, and adds no other.

**Owning guideline section.** `guidelines/FeatureList.md` §4 "The classification is the only human judgement, and
an unclassified spec stops the run" (routed by `AGENTS.md`'s Documentation Map row "the feature catalogue or the
release notes"; §2 states what the *catalogue* reads, which this change does not alter, and §9 lists what a change
owes).

## What changes

One mechanism: **the classification gate reads the capability ids an open change's delta specs introduce as well
as the ones the shipped set names.** `openspec/changes/<change>/specs/<capability>/spec.md` is the capability the
archive move is about to publish, so the same `--check-classification` call now fails while the change is open and
names both the id and the change that owes the line. `openspec/changes/archive/` is history and is not read.

Wiring, so the check runs at the moments that matter rather than in a suite nobody starts:

| where | what it gains |
|---|---|
| `tools/loop/gate.sh`'s profile (`tools/loop/loop.conf`) | `tools/gen-feature-list*.sh` and `tools/feature-list/*` owe the tool's suite; `openspec/*` owes the classification gate, so a change that writes a delta or moves its archive is gated on it |
| `.github/workflows/build.yml` | the tool's suite runs beside the classification step — until now its 115 cases ran in no CI step at all |
| `tools/gen-feature-list-selftest.sh` | a gate-shaped summary line (`<name>: all N cases passed`), which the gate's own summary regex reads (`tools/loop/gate.sh:114-118`, its shape asserted by `tools/loop-cases.sh`) — no gate run under this profile was made here |

`guidelines/FeatureList.md` §2, §4 and §9 and `README.md` say the widened rule; `.github/workflows/build.yml`'s
error message names it.

## Impact

- Affected files: `tools/gen-feature-list.sh`, `tools/gen-feature-list-selftest.sh`, `tools/loop/loop.conf`,
  `.github/workflows/build.yml`, `guidelines/FeatureList.md`, `README.md`, plus this change.
- Affected modules: none — no compiled file, no Gradle task, no device.
- Specs changed: `spec-feature-index` (one MODIFIED requirement; every other requirement untouched).
- Additive, not breaking: an installation, an archived change, and a capability already classified are unaffected.
  The only new failure is a delta whose capability the classification does not name — which the guideline already
  required, one archive too late.
- Rollback: revert the change directory. No data migration, no published document and no classification entry is
  written by this change.
