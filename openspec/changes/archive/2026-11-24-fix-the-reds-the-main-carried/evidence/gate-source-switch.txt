# Cause 8 — the source-switch case's registry reached the network

Measured 2026-11-24, after `c76b38f9` landed. The red is CI-only: the case's own fixture carried a real
`HttpUrlFetcher`, so the registry's refresh of the repository's region index opened a live HTTPS connection, and
the sandbox's SSL provider could not initialise.

## The red run

`Build Debug APK` run `45380057626` at `5e8ebbd6`, job "Build debug APK (all ABIs)", step "Run unit tests":

```

        at sun.security.ssl.SSLConfiguration.<init>(SSLConfiguration.java)
```

The same run's log shows the retry wrapper's two attempts before the case reached the network — the red was
hidden behind cause 6's throttle:

```
Maven Central rate limited a dependency download (429); retrying in 90s (attempt 1 of 3)
Maven Central rate limited a dependency download (429); retrying in 180s (attempt 2 of 3)
```

## The fixture as it stood

`app/src/test/java/com/naviveylin/ui/mapmanager/MapManagerSourceSwitchPlanTest.kt`, `viewModel()`:

```
val registry = MapSourceRegistry(settings, provider, HttpUrlFetcher())
```

`MapSourceRegistry`'s field is typed `RepositoryFetcher`, and the same package's other cases already build it with
`OfflineRepositoryFetcher()` (`MapManagerViewModelTestFactory.kt:64,75`) or `FakeRepositoryFetcher`. The real
fetcher was the outlier.

## The fix

The same file, `c76b38f9`:

```
val registry = MapSourceRegistry(settings, provider, OfflineRepositoryFetcher())
```

plus the removal of the now-unused `import com.naviveylin.data.HttpUrlFetcher`. The case asserts that a switch
keeping the target's basemap keeps it registered; neither that assertion nor its neighbours needs a listing.

## Named exclusion

The red direction of this fix is not reproduced locally: the case's network path needs a 429 to fall through the
wrapper's window, and this machine is not throttled. The red is the run's own — the title and the stack above —
and the green direction is the two filtered runs. The case's own subject (a basemap kept registered across a
switch) is unchanged, so the case's assertions are its proof.
