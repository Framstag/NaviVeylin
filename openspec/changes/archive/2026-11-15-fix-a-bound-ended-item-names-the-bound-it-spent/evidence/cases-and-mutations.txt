## the third arm this change states, which no mutation record pins

`spec.md`'s new scenario "A record written before the two fields is read by the bound its note names" describes a
derivation inside `bound_class_jq` (`tools/loop/lib.sh:326`), which reads a stopped item's own note back to the key
it names. No case asserts it: `run#aBoundEndedItemRecordsItsBound` writes the fields rather than reading a record that
predates them, so the derivation is pinned by nothing, and the commit `cdf0648c` records that in its own message
("No case pins that path yet"). This file names the hole rather than claiming a pin.
