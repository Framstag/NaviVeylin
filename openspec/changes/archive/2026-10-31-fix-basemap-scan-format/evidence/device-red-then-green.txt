# On-device: the stale basemap directory leaves the registered set (#716)

Device: `emulator-5554` (x86_64), mobile debug build, one regional map installed (`andorra`).
Fixture: `files/maps/basemap/basemap/` holding all 19 mandatory database files
(`MapDirectory::MandatoryFiles()`) with `types.dat` = little-endian `26`, i.e. a database
`MapDirectory::IsValid()` accepts and this build's reader (27) refuses. Prepared by
`.pi/base716/make_stale_basemap.py` on the host and created in place through `run-as`
(the shell allowlist refuses device-absolute paths in a command).
