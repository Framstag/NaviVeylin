Each is a **guideline section**, not a backlog `§`-issue: `guidelines/Backlog.recipes.md`:586 "Refusals, records
and the landing" and `guidelines/Backlog.recipes.md`:725 "Leftovers, the report and the queue". The check's pattern
is `§[0-9]\+` (`tools/loop/evidence-check.sh:68`), so it read the `§7` inside `§7d`/`§7e` as a citation of the
migration's `§ → issue` numbering, where no row 7 exists — two namespaces the check does not tell apart. The same
run over the open sibling changes reports the same class at this base
(`fix-a-bound-ended-item-is-recorded-cut` 3, `fix-a-cut-child-asks-no-question` 5, `fix-remote-heads-are-swept` 5).

## The correction

The four citations were repointed at the same sections by line, dropping the `§` the check misreads:
`guidelines/Backlog.recipes.md`:586 "Refusals, records and the landing" and `guidelines/Backlog.recipes.md`:725
"Leftovers, the report and the queue". No claim, figure or observation changed — only the form of the four
pointers.
